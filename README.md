# Моя тренировка — журнал комплекса упражнений

Ванильное веб-приложение (ES-модули, без сборщика, без npm-зависимостей, без CDN):
список упражнений с секциями, CRUD, прогресс, таймер подходов со звуком и Wake Lock,
приблизительная оценка расхода калорий. Данные — только `localStorage`; наружу ничего
не уходит (service worker кэширует лишь файлы самого приложения).

## Запуск

```cmd
cd /d "C:\Users\User\Documents\AI работа\Спорт и здоровье"
node server.js
```

Открыть <http://localhost:5173>.

Порт меняется переменной окружения: `set PORT=8080 && node server.js`.

## Запуск с телефона и публикация

Приложение — обычная статика: кладётся на любой хостинг (GitHub Pages, Netlify, свой сервер).
Всё нужное для «как приложение» уже в комплекте:

* `manifest.webmanifest` + иконки → «Добавить на домашний экран», запуск без адресной строки;
* `sw.js` → офлайн-режим (сеть приоритетнее, кэш как подстраховка): в зале без связи всё работает;
* `theme-color` совпадает с фоном, поэтому системная полоса не светится белым.

Проверить с телефона в домашней сети: `node server.js`, затем открыть `http://<IP компьютера>:5173`.
Установка на домашний экран и офлайн работают только по `http(s)`; с `file://` их не будет.
Важно: по локальному `http://` на iPhone service worker не регистрируется (не secure context),
поэтому офлайн-режим появляется только на HTTPS-хостинге.

## Два варианта интерфейса

Ядро одно (`src/logic.js`), данные одно (localStorage `workout.v1`) — меняется только слой показа,
поэтому прогресс, вес и список видны в обоих вариантах. Основной — «журнал»; прежний оставлен
как архив, чтобы можно было переключиться и сравнить.

| Вариант | Что это | Файлы |
| --- | --- | --- |
| основной «журнал» (корень) | тёмно-зелёная тема с лаймовым акцентом и светлая «бумажная», карточка «Прогресс сегодня», «Сейчас по плану», строки с круглым чекбоксом, «⋯»-меню, форма в нижнем листе | `index.html`, `styles.css`, `app.js` |

## Как ведёт себя список

- Выполненные упражнения убираются с экрана: список — это план на «осталось сделать».
- Когда упражнение отмечено, следующее встаёт на его место и подтягивается к верху экрана.
  Отступ прокрутки считается по фактической высоте липкой шапки (переменная `--scroll-offset`),
  поэтому карточка не прячется под шапкой ни на телефоне, ни на широком экране.
- Секция (разминка / основная часть / пресс), закрытая целиком, получает галочку рядом
  с подзаголовком; её счётчик показывает `N / N`.
- Когда выполнено всё, вместо списка — подсказка, где сбросить отметки.
- Снять отметку можно: кнопка «Показать выполненные · N» возвращает скрытые строки на экран
  (по умолчанию они скрыты).

## Оформление

Основной вариант: тёмно-зелёная тема с лаймовым акцентом (как в макете) — по умолчанию; переключатель
«тема» в шапке даёт ещё светлую «бумажную» и «авто» по системной настройке. Выбор хранится
в localStorage и применяется до первой отрисовки (без мигания чужой палитры), цвет системной полосы
(`theme-color`) меняется вместе с темой.

Вся палитра — переменные: `:root` описывает тёмную тему, `:root[data-theme="light"]` — светлую.
Правила ниже не знают, какая тема включена, поэтому третью тему можно добавить одним блоком.
Лайм в светлой теме остаётся только для заливок (полоса, чекбокс, баннер), а текст и обводки
переходят на глубокий зелёный — иначе контраст не проходит.

Геометрия там же: радиусы (`--r-card` / `--r-row` / `--r-btn`), высоты кнопок, акцентные градиенты.
Базовый кегль — 17px на телефоне и 16.5px на широком экране, тач-зоны не меньше 46px.

Иконки собираются скриптом: `python tools/make-icons.py` (Pillow, супер-сэмплинг 4×).

## Таймер

Отсчёт ведёт только `createTimer()` из `src/logic.js`; `src/app.js` подаёт время через
`requestAnimationFrame` и рисует снимок состояния. Перед каждым подходом — `leadin` на
3 сигнала («3», «2», «1» со звуком и пульсацией). После подхода таймер ждёт явного
«Следующий подход» — автозапуска нет.

Предупреждения считаются по числу уже поданных сигналов, а не по смене цифры на экране,
поэтому все три звучат даже при «залипании» кадра. При возврате вкладки из фона фоновое
время не засчитывается: таймер продолжается с места ухода, без перескока через подход.

## Звук

WebAudio-осциллятор, без внешних файлов: тихий тик (1000 Гц, 30 мс) раз в секунду,
заметный сигнал на каждой цифре `leadin`, отдельный сигнал окончания подхода и тройная
финальная последовательность. Все сигналы дублируются на экране, поэтому при выключенном
звуке сценарий не ломается.

## Wake Lock

Во время `leadin`/`work` запрашивается `navigator.wakeLock.request('screen')`, при
паузе/остановке/финише — освобождается, при возврате на вкладку — перезапрашивается.
Если API недоступен или запрос отклонён, один раз показывается сообщение в
`role="status"`, тренировка продолжается.

## Ограничения

* Оценка калорий — приблизительная (MET по названию, 3 с на повтор), не медицинский показатель.
* Планы по умолчанию (`leadIn`, `MAX_DT`) — константы в `src/app.js`.
* Реальный звук, Wake Lock и анимации проверяются только в браузере; автотестами покрыты
  ядро, разметка/импорты и HTTP-выдача.
